Drop chapter PDFs in this folder structure to make them available to all site visitors:

  /public/notes/class9/<chapter-slug>.pdf
  /public/notes/class10/<chapter-slug>.pdf
  /public/notes/class11/<chapter-slug>.pdf
  /public/notes/class12/<chapter-slug>.pdf

Slugs are lowercase, hyphenated. Examples:
  /public/notes/class12/solid-state.pdf
  /public/notes/class12/electrochemistry.pdf
  /public/notes/class10/acids-bases-and-salts.pdf

Once a file exists at the matching path, the site will pick it up automatically — no code change needed. Mark the chapter "available" from /admin if you want it visible to students.
